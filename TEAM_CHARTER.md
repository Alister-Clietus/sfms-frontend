# Team Charter

## Roles and Responsibilities
* **Tech Lead / Maintainer:** Approves architectural deviations, merges bootstrap PRs, manages DevOps configurations (DEVOPS-MAINT-001).
* **Backend Engineers:** Java 21, Spring Boot, PostgreSQL schema migrations.
* **Frontend Engineers:** Angular, RxJS, SCSS, Material Theme implementation.

## Working Agreements
* **Core Hours:** 10:00 AM - 3:00 PM (Local Time) for synchronous meetings.
* **Definition of Ready (DoR):** * Ticket has clear Acceptance Criteria.
  * UI/UX mockups are attached (if applicable).
  * API contracts are documented and agreed upon.

## Escalation Path
1. Peer review (Consult a fellow engineer).
2. Tech Lead review (Architectural blockers or cross-module dependencies).
3. Product Owner (Requirements clarification or scope changes).
